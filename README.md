## 內容

- **905** 條術語音檔（粵語旁白，英文術語保留英文發音）
- **13** 個章節專輯 + **12** 段章節敘述 + **14** 份時間碼表
- **905** 條術語選擇題 × **2 個語言版本**（中文／英文，頂部一按切換；可按章節或題型篩選，答錯可以重做）
- **12** 條短片、**12** 份溫習手冊 PDF
- **發音對照 A/B**：同一批術語，原讀法同新讀法各播一次

音檔全部 AAC 48 kbps 單聲道 M4A，iPhone、Android、車載機都直接播得。

## 技術細節

- 英文術語用「獨立一句 → 0.35 秒靜默 → 中文」拼出嚟，確保術語一定照英文讀，
  唔會因為後面即刻接住中文而被讀成中文譯名。中國字內容一字冇改。
- 全部音檔 32 kHz 單聲道，專輯用 `-c copy` 串，時間碼準到 0.1 秒以內。
- 專輯每個 cue offset 同對應嘅單條音檔比對過，相關係 1.000。
- 自我測驗每條題目都由同一份解釋改寫，選項係同章其他術語嘅真實意思，
  所以唔會有「obviously wrong」嘅假選項；答案附中文解釋同嗰條術語嘅音檔。
- 英文版係中文版嘅逐題翻譯：同一批題目、同一個答案位置、同一個 id，
  由 build script 自動核對兩邊係咪對得返。
- 每題顯示嗰四個選項都會重新洗牌，所以答案位置唔會每次都一樣；
  資料入面保存嘅答案索引亦都平均分布喺 0–3。
- 英文版唔會播音檔 —— 音檔係「英文術語 → 中文解釋」，喺英文版度會撞板。
