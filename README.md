## 由零開始 · 今日 90 分鐘

第一次接觸呢門課，唔好由 905 條術語開始。按下面四步做：

| # | 做咩 | 連結 | 時間 |
|---|---|---|---|
| 1 | 睇兩條短片，知道目標係咩 | [V02 收縮環 → 雙核細胞](https://rollroyces.github.io/gnbf5020-study-kit/videos/assets/V02_Contractile_ring_binucleated_cell.mp4) · [V03 NHEJ 缺陷 → SCID](https://rollroyces.github.io/gnbf5020-study-kit/videos/assets/V03_NHEJ_defect_SCID.mp4) | 10 分鐘 |
| 2 | 讀入門指南 **Part 0（第 7–12 頁）**：點用本書、英文作答規則、五講地圖、點計分、六十秒定位 | [Beginners' Guide（英文原文）](https://rollroyces.github.io/gnbf5020-study-kit/pdf/GNBF5020_Beginners_Guide.pdf) · [繁體中文版](https://rollroyces.github.io/gnbf5020-study-kit/pdf/GNBF5020_%E6%96%B0%E6%89%8B%E5%85%A5%E9%96%80%E6%8C%87%E5%8D%97_%E7%B9%81%E9%AB%94%E4%B8%AD%E6%96%87.pdf) | 20 分鐘 |
| 3 | 讀 **Chapter 1「化學從零開始：從 atom 到 molecule」（第 14–24 頁）**，用書本嘅章節格式：n.1 詞語 → n.2 大局觀 → n.3 逐段拆解 → n.4 要記住嘅 12 件事 → n.5 自我檢查 | 同上（英文原文） | 60 分鐘 |
| 4 | 聽返嗰幾條術語嘅音檔，用英文把術語講出嚟 | [有聲版](https://rollroyces.github.io/gnbf5020-study-kit/index.html) | 10 分鐘 |

之後每日一章，跟住讀 Chapter 2 → 7（基礎篇：化學、biomolecule、蛋白質、DNA 與染色體、細胞、細胞點運作、詞彙表），再開始 Lecture 1。

> **最重要嗰一條規則：所有作答一律用英文。**
> 黃教授講過三次，去年有同學用中文作答，佢直接俾零分（見 Beginner's Guide §0.2）。
> 所以 **英文版嘅 PDF 係原文，中文版係翻譯**；温習用英文原文，考試用英文作答。

## 技術細節

- 英文術語用「獨立一句 → 0.35 秒靜默 → 中文」拼出嚟，確保術語一定照英文讀，
  唔會因為後面即刻接住中文而被讀成中文譯名。中國字內容一字冇改。
- 全部音檔 32 kHz 單聲道，專輯用 `-c copy` 串，時間碼準到 0.1 秒以內。
- 專輯每個 cue offset 同對應嘅單條音檔比對過，相關係 1.000。
- 自我測驗每條題目都由同一份解釋改寫，選項係同章其他術語嘅真實意思，
  所以唔會有「obviously wrong」嘅假選項；答案附中文解釋同嗰條術語嘅音檔。
- 英文版係中文版嘅逐題翻譯：同一批題目、同一個答案位置、同一個 id，
  由 build script 自動核對兩邊係咪對得返。
- 每題顯示嗰四個選項都會重新洗牌，所以答案位置唔會每次都一樣；
  資料入面保存嘅答案索引亦都平均分布喺 0–3。
- 英文版唔會播音檔 —— 音檔係「英文術語 → 中文解釋」，喺英文版度會撞板。
