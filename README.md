## 內容

- **905** 條術語音檔（粵語旁白，英文術語保留英文發音）
- **13** 個章節專輯 + **12** 段章節敘述 + **14** 份時間碼表
- **40** 條短片（16 條全課 + 12 條第六課 + 12 條第七課）、**22** 份溫習手冊 PDF
- **地基課程**：八個單元 + 全課 905 條術語的完整詞彙表（中英兩版）
- **自我測驗**：905 題，中／英切換
- **第六課粵語有聲版**：19 節、58 條
- **第七課粵語有聲版**：19 節、73 條（Genomic Applications in Biomedical Research）
- **發音對照 A/B**：同一批術語，原讀法同新讀法各播一次

音檔全部 AAC-LC 單聲道 32 kHz M4A（編碼目標 50 kb/s），iPhone、Android、車載機都直接播得。

## 技術細節

- 英文術語用「獨立一句 → 0.35 秒靜默 → 中文」拼出嚟，確保術語一定照英文讀，
  唔會因為後面即刻接住中文而被讀成中文譯名。中國字內容一字冇改。
- 全部音檔 32 kHz 單聲道，專輯用 `-c copy` 串，時間碼準到 0.1 秒以內。
- 專輯每個 cue offset 同對應嘅單條音檔比對過，相關係 1.000。
